## 📊 SpeedCheck Line Chart ##
- This project is a mobile-responsive line chart built with React, Chart.js, and Vite, inspired by the design and functionality of SpeedCheck's visual analytics. It visualizes dummy internet speed test data including Download, Upload, and Ping values from different ISPs.


## 🛠 Tech Stack ##
 - React
 - Vite
 - Chart.js
 - react-chartjs-2
 - CSS

## 📦 Installation & Setup ##
## Clone this repo ##

 - git clone https://github.com/your-username/speedcheck-linechart.git
 - cd speedcheck-linechart
 ## Install dependencies ##

 - npm install
## Start the development server ##

 - npm run dev

## Build for production ##

 - npm run build

## 📊 Dummy Data Details ##
 Each tab represents a category of internet performance:

 - Download Speed (Mbps)

 - Upload Speed (Mbps)

 - Ping (ms)
